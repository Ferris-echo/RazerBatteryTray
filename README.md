# 雷蛇鼠标电量托盘小工具 (RazerBatteryTray)

一个专门为雷蛇无线/有线鼠标打造的**超轻量级 Windows 任务栏托盘电量指示器**。

无需安装或启动臃肿的 **Razer Synapse (雷云)**，即可在屏幕右下角任务栏托盘直观查看鼠标实时电量与充电状态！

---

## 🌟 核心特性

1. **摆脱臃肿雷云**：
   - 雷云 3/4 占用数百兆内存与数十个后台服务/分析进程；
   - 本工具仅约 **35 KB** 单文件，内存占用仅 **15~35 MB**，CPU 占用 **0%**。
2. **专属定制雷蛇电竞鼠标图标**：
   - 软件与快捷方式全面换装专属高精矢量雷蛇游戏鼠标图标（`app.ico`，多分辨率 256x256 ~ 16x16 适配），桌面与任务栏质感拉满。
3. **托盘图标三重主题切换**（右键菜单随时切换）：
   - **现代胶囊电池（推荐）**：Windows 11 / iOS 现代极简圆角电池，带正极触点与流光能量条，充电时呈现高亮闪电符号（`⚡`）；
   - **电竞极简能量环**：极具科技感的智能环形能量条 + 居中电量数字；
   - **醒目数字能量表**：高对比度数字牌 + 底部彩色状态条。
4. **可视化电量面板 + 托盘双模式**：
   - Windows 11 沉浸式暗色标题栏，搭配雷蛇绿 Chroma 卡片式模块；
   - 完美适配 2.5K/4K 屏幕 150% 高分屏缩放，字体组件不再截断；
   - 点击面板上的「最小化到托盘」或关闭按钮，程序将自动隐入系统托盘默默守护。
5. **零外部运行库依赖**：
   - 基于 Windows 10/11 原生自带的 .NET Framework 4.8 构建，不需要安装 Python、Node.js 或 Electron 环境；
   - 采用原生 Windows HID API (hid.dll) 直接与鼠标通信，**无需管理员权限（不需要 UAC 弹窗）**。
6. **贴心右键菜单**：
   - **显示状态面板**：随时唤出中央电量卡片；
   - **托盘图标样式**：一键切换胶囊电池 / 能量环 / 数字表；
   - **立即刷新 (Refresh)**：随时手动更新最新电量；
   - **刷新频率调节**：可按需选择 30 秒、1 分钟（推荐）、5 分钟轮询间隔；
   - **开机自动启动**：一键勾选即可随系统后台启动（写入用户注册表 Run 项）；
   - **低电量提醒**：电量低于 20% 且未充电时，弹出系统通知气泡提醒充电；
   - **安全退出**：彻底关闭并释放系统资源。

## 🚀 使用方法

1. **桌面快捷方式**：
   - 桌面上已有专属图标的快捷方式：`雷蛇鼠标电量托盘.lnk`。双击即可打开电量面板并启动托盘服务。
2. **在任务栏常显图标**：
   - Windows 11/10 默认会将所有新软件的托盘图标收纳在任务栏右下角的 **「^」折叠箭头** 内。
   - 您可以点击任务栏右下角的 **^** 展开抽屉，即可看到精美的电池小图标；
   - **强烈建议**：用鼠标左键按住该图标，直接把它**拖拽**到任务栏右下角的常驻区域，即可一直保持在外面常显！
